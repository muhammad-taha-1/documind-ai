# Screenshots

Images for the project README. Use PNG, about 1440 px wide, with the app in its default (dark) theme.

| File            | What to show                                                             |
| --------------- | ------------------------------------------------------------------------ |
| `dashboard.png` | The documents page with a few documents, ideally one still processing    |
| `chat.png`      | A chat answer with `[Source N]` citations and the sources list opened    |
| `document.png`  | A document's page with a cited passage highlighted (`?chunk=`)           |
| `vision.png`    | A chat where an image (a chart or screenshot) was attached and explained |

Once they're here, uncomment the image links in the Screenshots section of the main README.
